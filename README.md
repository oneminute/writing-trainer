# Writing Trainer

Writing Trainer is a local-first adaptive English-writing system for a sixth-grade ESL learner.

## Deterministic curriculum

The learning plan is **not generated by the LLM**. The authoritative curriculum lives in `src/plan.js` and is seeded/upserted into SQLite every time the server starts.

Current curriculum:
- 12 stages
- 52 detailed lessons
- stage goals, advancement rules, prompt mode, expected output length, and generation guardrails
- lesson objectives, grammar rules, common errors, prompt-pattern examples, required elements, exclusions, and difficulty guidance

SQLite tables:
- `curriculum_stages`
- `curriculum_lessons`
- `lesson_attempts`

The Plan page reads the curriculum back from SQLite. Qwen/OpenAI only receives the exact lesson selected by the deterministic planner and must follow its item-by-item guidance.

## Learning loop

Deterministic curriculum → daily planner → exact lesson guidance → local/OpenAI exercise generation → writing check → skill + lesson evidence → SQLite history → spaced review → progress dashboard.

## Stage progression

Stage progression is now lesson-based. A lesson needs repeated evidence and mastery before it stops blocking the next stage. Broad skill mastery is still tracked separately for long-term trend analysis.

## Local generation

Exercise generation is batched for local models. By default:
- check timeout: 60 seconds
- generation timeout: 180 seconds per batch
- generation batch size: 4

The generator is constrained by the database curriculum; it does not choose the curriculum.

## Practice persistence

Every generated set is permanently archived. Practice sessions save:
- current question
- draft answer
- attempt count
- hint level
- model-answer usage
- final correctness
- first-try correctness
- independent correctness

Old sets can be replayed from **Sets** without calling the LLM.

## Pages

- **Today** — planned daily practice
- **Plan** — detailed 12-stage / 52-lesson curriculum
- **Review** — spaced review queue
- **Progress** — lesson and skill mastery, trends, error drill-down
- **Sets** — saved practice sets and replay
- **History** — filtered answer/check history
- **Settings** — practice configuration

## Windows

Double-click `start-writing-trainer.bat` for local use or `start-writing-trainer-lan.bat` for home-LAN use.

Launchers run `npm test` before startup. The test performs syntax checks plus an isolated SQLite/API smoke test.

SQLite learning data is stored in `data/writing-trainer.db` and is ignored by Git.
