## First promotion wave

Recommended order:

1. local LLM / Ollama community
2. Hacker News
3. developer social channels
4. Chinese technical community
5. ESL / education feedback communities

## Success signals

For the first 7 days, track:

- stars
- forks
- unique contributors
- issues opened
- installation questions
- grading-regression reports
- feature requests
- local-model compatibility reports

The most valuable signal is not raw stars. It is whether unrelated users can install the project and complete a real practice session without help from the author.
